# Tetris Game

A classic Tetris game built with HTML5, CSS, and JavaScript. The game works fully offline and supports both touch and gamepad controls.

## Features

- Classic Tetris gameplay
- Responsive design for desktop and mobile
- On-screen touch controls and gamepad support
- Synthesized Tetris theme and sound effects
- Ghost piece to show where the tetromino will land
- Next piece preview
- Score tracking and high score saving
- Level progression with increasing speed

## How to Play

- Arrow keys to move and rotate pieces (or use a connected controller)
- Spacebar for hard drop
- P to pause
- M to mute/unmute

## Technologies Used

- HTML5 Canvas
- CSS
- JavaScript (Web Audio API)
